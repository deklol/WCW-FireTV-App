# Wrestling Chronology

Wrestling Chronology is a separate app covering WCW, ECW, WWF/WWE and TNA/Impact, with chronological playback.

The WCW app introduces it after the opening screen. Choose **Download and install**, **Not now**, or **Don't show again**. The last option is saved separately from viewing history and suppresses future launch notices. The notice also stays hidden if the new app is already installed.

You can always return to **Settings → Wrestling Chronology**. If the new app is installed, this entry offers **Open app**. It also provides **GitHub / Downloader** installation options regardless of the startup preference.

## Direct installation

The app fetches the current stable release from the project's GitHub API, downloads `Wrestling-Chronology.apk`, checks its GitHub-provided SHA-256, package name, version and minimum Android requirement, then opens the device's package installer. Existing copies must have the same signing certificate and cannot be downgraded. You confirm installation through Fire TV's normal installer.

Allow WCW Chronology to install apps from unknown sources. On Fire OS 7 and newer, this is normally under **Settings → My Fire TV → Developer Options → Install unknown apps**. On Fire OS 6 it may be a global **Apps from Unknown Sources** switch. The app offers the system permission page where available and explains the manual route otherwise.
